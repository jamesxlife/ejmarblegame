EJ'S FOOTBALL MARBLE CUP
=========================

READY-TO-HOST STATIC WEBSITE

Files:
- index.html  : main web page
- style.css   : visual styling
- game.js     : game logic, physics, JOLT button and leaderboard

HOW TO TEST LOCALLY
1. Extract this ZIP file.
2. Double-click index.html.
3. The game will open in your web browser.

HOW TO HOST
Upload all three files together, keeping their names unchanged.
The hosting service should serve index.html as the homepage.

No React installation, npm, database or server-side code is required.
